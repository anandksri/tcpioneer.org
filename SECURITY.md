# Security Policy

TC Pioneer is a cybersecurity education and community platform. Security reports that affect the website, services, or repository are welcome.

## Reporting a Vulnerability

Please report vulnerabilities privately rather than publishing sensitive details in a public issue.

Include:

- A clear description of the issue
- The affected page, endpoint, or component
- Reproduction steps
- Security impact
- A safe proof of concept when useful

Do not include real credentials, tokens, personal information, or other sensitive data in reports.

## Responsible Disclosure

Please allow reasonable time for investigation and remediation before publicly disclosing technical details.

## Scope

This policy covers the website source and security-relevant components maintained in this repository.
