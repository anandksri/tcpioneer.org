# Contributing to TC Pioneer

Contributions that improve cybersecurity education, documentation, accessibility, security, and project quality are welcome.

## Before Contributing

- Read the repository documentation first
- Keep changes focused and easy to review
- Verify links and examples where practical
- Do not commit secrets, credentials, or private information
- Follow responsible security research practices

## Pull Requests

For larger changes, open an issue first to discuss the proposed work.

Pull requests should explain what changed and include relevant testing or verification details.

## Security Issues

Do not publish sensitive vulnerability details in a public issue. Follow `SECURITY.md` for security reports.
